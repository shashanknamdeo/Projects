# Gossipy

Gossipy is a **voice-based generative AI chat application** that allows users to interact with AI using **natural voice conversations**. The system converts voice to text, generates AI responses, and converts them back into speech.

## Tech Stack
- **React Native / TypeScript / Expo**: Frontend mobile framework
- **AWS Amplify Auth**: Authentication
- **AWS Transcribe / Amazon Polly**: Voice Pipeline (Speech-to-Text and Text-to-Speech)
- **Google Gemini API**: AI Generation
- **React Hooks**: State Management

For architectural details, see the `docs/` folder. The primary source code is located in the nested `Gossipy/` directory.
