## 1. HireIQ
📁 **Project Folder:** [View Project](./HireIQ)

HireIQ is an **automated job application and job-matching platform** designed to streamline the job search process.

The system automatically discovers job listings, analyzes job descriptions, matches them with resumes using **AI/NLP techniques**, and tracks application progress.

### Tech Stack

- **Python** – Core programming language for automation and backend logic  
- **Django** – Backend framework for APIs and application logic  
- **PostgreSQL** – Database for storing job listings and applications  
- **Selenium** – Automation and scraping of dynamic job portals  
- **BeautifulSoup** – HTML parsing and data extraction  
- **REST APIs** – Communication between system components  
- **Worker-based Architecture** – Modular background workers  
- **AI/NLP Matching** – Resume and job similarity scoring  
- **Structured Logging** – Monitoring and debugging  
- **AWS Elastic Beanstalk** – Cloud deployment

## 2. IntelliTrade
📁 **Project Folder:** [View Project](./IntelliTrade)

IntelliTrade is an **AI-powered trading assistant** that analyzes financial data, generates trading insights, and helps users understand market trends using predictive models.

### Tech Stack

- **API Layer:** Django REST Framework (DRF)

- **DevOps:** Docker, Git, GitHub

## 4. Gossipy
📁 **Project Folder:** [View Project](./Gossipy)

Gossipy is a **voice-based generative AI chat application** that allows users to interact with AI using **natural voice conversations**.

The system converts voice to text, generates AI responses, and converts them back into speech.

### Tech Stack

- **Frontend:** React Native + TypeScript  
- **Authentication:** AWS Amplify Auth  
- **Speech-to-Text:** AWS Transcribe  
- **AI Generation:** Google Gemini API  
- **Text-to-Speech:** Amazon Polly  
- **Voice Pipeline:** Speech → Text → AI → Speech  
- **State Management:** React Hooks  
- **Mobile Framework:** Expo / React Native  
- **Cloud Platform:** AWS

## 5. SNK App
📁 **Project Folder:** [View Project](./SNK-App)

SNK App is a **mobile file synchronization and backup system** that manages file storage and cloud backups while ensuring data integrity and efficient syncing.

### Tech Stack

- **React Native** – Cross-platform mobile development  
- **TypeScript** – Strongly typed JavaScript  
- **AWS Amplify** – Backend services and integration  
- **Amazon S3** – Secure cloud storage  
- **Amplify Auth** – Authentication system  
- **React Native FS (RNFS)** – Local file access  
- **CryptoJS / MD5** – File integrity verification  
- **AsyncStorage** – Local persistence  
- **NetInfo API** – Network detection  
- **Manifest Sync Engine** – Efficient file comparison
