Create User Registration API

Create a new file: authentication/serializers.py

Paste:

from django.contrib.auth.models import User
from rest_framework import serializers

class RegisterSerializer(serializers.ModelSerializer):

    class Meta:
        model = User
        fields = ['username', 'email', 'password']

    def create(self, validated_data):
        user = User.objects.create_user(
            username=validated_data['username'],
            email=validated_data['email'],
            password=validated_data['password']
        )
        return user

Note : Use create_user() intead of create(), Because create_user() hashes the password.

class RegisterView(generics.CreateAPIView):
    queryset = User.objects.all()
    serializer_class = RegisterSerializer
    permission_classes = [AllowAny]

Change Password Field (Registration API)

Currently the password may appear visible in the form.
To fix that, update the serializer:

Open : authentication/serializers.py

Add 'extra_kwargs' in 'Meta' class

class Meta:
        model = User
        fields = ['username', 'email', 'password']
        extra_kwargs = {
            'password': {'write_only': True}
        }

Register request flow :

POST request (urls.py -> authentication.urls.py)
RegisterView (view.py)
    validate data (internally in serializer)
    save user serializer.py (internally in serializer)
        create() (wite in serializer.py, but call under serializer.save())
    return response (internally in serializer)


More Detailed Request Flow : (for understanding)

Client (Browser / Postman)
HTTP Request
POST /api/auth/register/
Django URL Resolver
Project urls.py
authentication/urls.py
RegisterView # view.py
    CreateAPIView.create()
        Extract POST data (request.data)
        serializer = RegisterSerializer(data=request.data)
        serializer.is_valid() (validates request data)
        serializer.save()
            RegisterSerializer.create(validated_data) # serializer.py
                User.objects.create_user()
                    password hashed
                    user saved in DB
        serializer.data (convert User model → JSON)
        Response(serializer.data)
    DRF builds HTTP Response
JSON returned to client

-------------------------------------------------

Protected API Request Flow :

Client (Browser / Postman)
HTTP Request : GET /api/auth/test-auth/
Project urls.py
authentication/urls.py
TestAuthView - APIView.dispatch()
    initialize_request() (converts Django request → DRF Request object : To access request.data, request.user, request.auth)
    JWTAuthentication.authenticate(request) (JWT Authentication check)
        1. Read Authorization header
        2. Extract token
        3. Decode JWT
        4. Verify signature
        5. Check expiration
        6. Extract user_id
        7. Fetch user from DB
        8. If valid : request.user = authenticated user
    permission_classes = [IsAuthenticated]
        IsAuthenticated.has_permission() {
            if request.user is authenticated : Return Yes, User Authorized
            else : Return 401 Unauthorized
            } (JUST FOR UNDERSTANDING)
    TestAuthView.get()
        Response returned
    DRF Organise response into HTTP Response (Status Code, Respnse JSON etc)
