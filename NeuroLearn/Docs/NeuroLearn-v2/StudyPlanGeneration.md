
# NeuroLearn – Content Generation Flow (Gen AI)

The NeuroLearn system generates structured learning content automatically using Generative AI.

The generation process follows a **hierarchical learning structure** so that learning remains organized, progressive, and aligned with the user’s study plan.

NeuroLearn uses **micro-learning units**, where each concept is immediately validated with a quiz.

---

# 1. Study Plan Creation (Entry Point)

When a user creates a **Study Plan**, the system collects parameters such as:

* Topic / Subject    : example - Python
* Number of Days
* Daily Study Time
* User Skill Level   : example - Basic, intermidiate, etc
* User stream        : example - Science / Engineering, arts, commerce, etc
* Learning Goals     : example - Job, Exam, etc
* Age Group          : below 18, 23–30, etc

These parameters are used to generate the **learning structure**.

```
User Input
   │
   ▼
Study Plan Generator (Gen AI Prompt)
```

---

# 2. Topic Generation

The system first breaks the **main subject** into **high-level topics**.

Example:

Topic: Data Structures

Generated Topics:

1. Introduction to Data Structures
2. Arrays
3. Linked Lists
4. Stacks and Queues
5. Trees Basics

```
Main Subject
   │
   ▼
Topics (Generated by AI)
```

Topics organize the **overall learning roadmap**.

---

# 3. Session Generation (Daily Learning)

Each topic is divided into **sessions**, where each session represents **one day of study**.

Example:

```
Day 1 Session
   Topic: Introduction to Data Structures
```

Structure:

```
Study Plan
   │
   ├── Day 1 Session
   ├── Day 2 Session
   ├── Day 3 Session
   └── ...
```

Each **session corresponds to the user's daily study time**.

---

# 4. Sub-Session Topic Generation

Each session is further divided into **sub-sessions**.

A **sub-session represents a small concept** that can be learned quickly.

Rules:

* Each sub-session focuses on **one concept**
* Each sub-session takes **≤ 20 minutes**
* Multiple sub-sessions can exist within a session

Example:

Session: Arrays

Sub-Sessions:

1. What is an Array
2. Array Memory Representation
3. Array Indexing

```
Session
   │
   ├── Sub-Session 1
   ├── Sub-Session 2
   └── Sub-Session 3
```

---

# 5. Learning Unit Generation

NeuroLearn treats each **Sub-Session as a Learning Unit**.

Each learning unit contains **three tightly connected components**:

```
Learning Unit
   │
   ├── Sub-Session Content
   ├── Quiz
   └── Quiz Explanation
```

These three elements are **generated together using a single AI prompt**.

This ensures **conceptual consistency** between:

* the concept being taught
* the quiz question
* the explanation for incorrect answers

---

# 6. Sub-Session Content Generation (.md)

For each sub-session, the system generates **learning content in Markdown format**.

The content may include:

* Explanation
* Examples
* Key concepts
* Important notes
* Code snippets (if applicable)

Example:

```
content.md

# What is an Array

An array is a data structure that stores elements in
contiguous memory locations.

## Key Idea

Elements are accessed using an index.

## Example

arr[0] → first element
arr[1] → second element
```

```
Sub-Session
   │
   ▼
Markdown Content (.md)
```

---

# 7. Quiz Generation (Per Sub-Session)

Immediately after each sub-session, the system generates a **quiz question** to validate understanding.

Quiz Types:

* Multiple Choice Questions
* Multiple Correct Answers
* Concept Validation Questions

Example:

```
Quiz

Q: Which property is true about arrays?

A. Dynamic size
B. Continuous memory allocation
C. No indexing
D. Random memory storage

Correct Answer: B
```

---

# 8. Quiz Explanation

The AI also generates a **quiz explanation** together with the quiz.

However, the explanation is **shown only if the user answers incorrectly**.

Example explanation:

```
Explanation

Arrays store elements in continuous memory locations.

This allows constant-time access using indexes.
```

Behavior:

```
User Answer
   │
   ├── Correct
   │      → Continue to next sub-session
   │
   └── Incorrect
          → Show explanation
```

---

# 9. Learning Flow

The learning process follows this loop:

```
User Opens Session
       │
       ▼
Read Sub-Session Content
       │
       ▼
Attempt Quiz
       │
       ├── Correct
       │      │
       │      ▼
       │   Next Sub-Session
       │
       └── Incorrect
              │
              ▼
       Show Quiz Explanation
```

---

# 10. AI Generation Strategy

NeuroLearn uses **two levels of AI generation**.

### 1️⃣ Study Plan Generation

Creates the learning structure:

```
Topics
Sessions
Sub-Session Topics
```

### 2️⃣ Learning Unit Generation

For each sub-session:

```
AI Prompt
   │
   ▼
Generate Learning Unit
   ├── Sub-Session Content
   ├── Quiz
   └── Quiz Explanation
```

One prompt generates **exactly one learning unit**.

---

# 13. Key Design Principles

NeuroLearn follows these principles:

* **Micro-Learning** → small concepts reduce cognitive overload
* **Immediate Feedback** → quiz after each concept
* **Concept Validation** → ensures real understanding
* **AI Consistency** → one prompt generates the learning unit

This design ensures that students **learn concepts step-by-step and validate understanding continuously**.
