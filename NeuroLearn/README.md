# NeuroLearn

NeuroLearn is an **AI-powered learning assistant** that helps students study efficiently by generating **study plans, explanations, and quizzes using large language models**.

## Tech Stack
- **Python / Django / DRF**: Backend API layer
- **React.js**: Frontend Client
- **PostgreSQL**: Database
- **JWT**: Authentication
- **LLM APIs**: Generative AI Integration
- **Celery + Redis**: Background Jobs
- **Docker**: Containerization
- **AWS (EC2, S3, RDS)**: Deployment

For architectural details, see the `docs/` folder.
