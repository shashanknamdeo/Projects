# HireIQ

HireIQ is an **automated job application and job-matching platform** designed to streamline the job search process. The system automatically discovers job listings, analyzes job descriptions, matches them with resumes using **AI/NLP techniques**, and tracks application progress.

## Tech Stack
- **Python / Django**: Backend logic and REST APIs
- **PostgreSQL**: Database for storing job listings and applications
- **Selenium / BeautifulSoup**: Automation and scraping of dynamic job portals
- **AI/NLP**: Resume and job similarity scoring
- **Workers**: Asynchronous background tasks
- **AWS Elastic Beanstalk**: Cloud deployment

For architectural details, see the `docs/` folder.
