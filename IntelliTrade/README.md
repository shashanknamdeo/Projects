# IntelliTrade

IntelliTrade is an **AI-powered trading assistant** that analyzes financial data, generates trading insights, and helps users understand market trends using predictive models.

## Tech Stack
- **Python / Django / DRF**: Backend API layer
- **React.js**: Frontend dashboard
- **PostgreSQL**: Database
- **Pandas / NumPy / Scikit-learn / TensorFlow**: Data processing and AI models
- **WebSockets**: Real-Time Data and market APIs
- **Celery / Redis**: Task Queue
- **AWS (EC2, S3, RDS)**: Cloud Infrastructure

For architectural details, see the `docs/` folder.
