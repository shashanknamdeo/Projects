# SNK

SNK is a **mobile file synchronization and backup system** that manages file storage and cloud backups while ensuring data integrity and efficient syncing.

## Tech Stack
- **React Native / TypeScript**: Cross-platform mobile development
- **AWS Amplify / S3 / Cognito**: Backend services, storage, and authentication
- **React Native FS (RNFS)**: Local file access
- **CryptoJS / MD5**: File integrity verification
- **AsyncStorage**: Local persistence
- **Manifest Sync Engine**: Efficient file comparison

For architectural details, see the `docs/` folder. The main application is located in `SnkApp/`.
